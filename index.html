How to Use Deen Chat

Your Serial ID

Every user gets a unique 4-digit Serial ID when they join.

Your ID: #0000
  • Find your ID next to your name (top-right)
  • Share it with others so they can message you
  • Your ID never changes

Friend Request System

To start a private chat:

  • Click New Chat in the sidebar and enter the other person's 4-digit ID
  • A request is sent — they must accept it first
  • Once accepted, both sides can chat freely
Incoming requests appear at the top of your sidebar with an orange border.

Groups

  • Click New Group in the sidebar to create a group
  • Add members by contacts or Serial ID
  • Group admin can add/remove members

Profile Picture

  • Upload your photo to Imgur, Google Drive, etc.
  • Paste the direct image URL in profile settings

Online Status

  • Green dot = Online
  • Gray dot = Offline (shows last seen time)

Other Features

  • Edit Profile: Click your profile badge (top-right)
  • Dark Mode: Use the Dark/Light button

Privacy Note

Private chats are only between you and the other person.
